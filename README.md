# Aurora Wellness 🌟

A comprehensive health and wellness tracking app built with Flutter.

## Features

- 🚶 **Step Tracking** - Automatic step counting with pedometer
- 💧 **Water Intake** - Track daily hydration goals
- 😴 **Sleep Tracking** - Monitor sleep patterns and quality
- 🍎 **Calorie Tracking** - Log meals and track nutrition
- ❤️ **Health Metrics** - Blood pressure, blood sugar monitoring
- 🏆 **Social Challenges** - Compete with friends
- 📊 **Analytics** - Weekly and monthly charts
- 🌙 **Dark Mode** - Beautiful light and dark themes
- 🔐 **User Authentication** - Secure login with Firebase

## Getting Started

### Prerequisites

- Flutter SDK (>=3.0.0)
- Dart SDK (>=3.0.0)
- Android Studio / VS Code
- Firebase account

### Installation

1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/aurora-wellness.git
cd aurora-wellness
```

2. Install dependencies
```bash
flutter pub get
```

3. Configure Firebase
   - Create a new Firebase project
   - Add your `google-services.json` (Android) and `GoogleService-Info.plist` (iOS)
   - Enable Authentication and Firestore

4. Run the app
```bash
flutter run
```

## Tech Stack

- **Flutter** - UI Framework
- **Firebase** - Backend & Authentication
- **Provider** - State Management
- **FL Chart** - Charts and graphs
- **Pedometer** - Step counting
- **SharedPreferences** - Local storage
